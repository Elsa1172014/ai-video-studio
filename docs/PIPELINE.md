# Production pipeline

1. Script and scene plan
2. Per-scene visual generation (Wan/LTX)
3. TTS or permitted voice clone
4. Avatar animation (LivePortrait/EchoMimic)
5. Lip sync (MuseTalk)
6. Whisper transcription/alignment and captions
7. Remotion/FFmpeg composition and final MP4

Long videos are generated scene-by-scene. Character/style reference assets are reused across scenes to improve continuity. Voice cloning should require affirmative consent from the voice owner.
